## 硬约束
1. [scope: all] 可拆分、可并行的耗时任务积极用 delegate_task；子代理只做独立、只读或互不写同一文件的任务，prompt 带全上下文和验收标准，结果由主会话核验；即时命令、需看屏/交互的操作直接做，不派发。
2. [scope: all] 无红线、无真实阻塞、无需授权时，自行调研→决策→推进；尽量后台/headless，做完再报；遇到红线、缺权限/凭据、不可逆操作或无法自行验证的成本/风险，才停下来问。
3. [scope: all] 网页搜索/抓取优先用 DeepSeek 官方 Search / Fetch API；不要把搜索请求塞进对话模型；接口不可用时再用内置 web_search / web_extract，并说明。
4. [scope: all] 当前 Hermes 为 v0.22.2 稳定版；优先用内置技术栈（python 3.14.7 / git 2.53.0+3 / node 26.7.0 / npm 12.0.2 / uv 0.12.3，位于 %LOCALAPPDATA%\hermes\tools\）。
5. [scope: all] 只处理本对话负责的项目（会话指定的项目根，含 AGENTS.md 所在仓；没有就取 workdir 的 git 仓）。有纳入版本控制的改动，按可交付粒度提交；收尾 push 当前分支到 origin 并核对 HEAD。提交前只暂存本任务文件，不提交别的 session 未完成的改动；push 前过凭据/隐私/绝对路径自检；有测试/自检先跑，失败不 push。
6. [scope: all] 别的 session/项目不主动查、不主动报、不主动动，除非我明确点名；点名只解除查看/汇报限制，不构成红线授权。红线优先于硬约束。

1. 禁止重启/停止/升级/降级 Hermes、网关、桌面后端；已授权的自动恢复任务除外。
2. 禁止改 Hermes 的 SOUL、凭据、config、源码、工具目录或 HUD 规则文件（panel.md/hud_inject.py）；项目自身 config 按项目规则处理。

4. 禁止把仓库改为公开、对外发布或发 Release；向已有公开仓库正常 push 不在此列；push 前过凭据、隐私、本机绝对路径三项自检。
5. 除 DeepSeek 官方 API 外，未经预算批准不得产生费用；跑批带 --max-cost/--max-calls。
6. 禁止不可逆的磁盘/设备操作（分区、格式化、刷 BIOS、禁用 PnP 设备等）。
7. 禁止杀/停别的对话的进程与在跑任务，禁止改别线的仓；headless/cron/subagent 遇到需授权事项，停止并报告，不等待、不猜测、不复用旧授权。
